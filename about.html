About SafeLink

A static shortlink & safelink generator. Built for monetization, deploy anywhere.

What is SafeLink?

SafeLink is a static website that lets you create short URLs (like domain.com/s/?id=abc123) and safelink pages — intermediate pages that show an article and a countdown timer before redirecting visitors to their destination. It is designed to be deployed to GitHub Pages, cPanel, Netlify, Vercel, Cloudflare Pages, or any static web host, with absolutely no server-side code or database required.

Why we built it

Most existing shortlink services either cost money, run ads that you cannot control, or store your data on servers you do not own. SafeLink flips that model: you deploy it on your own hosting (GitHub Pages, cPanel, Netlify, etc.), and you keep full control over every link and every ad slot.

The project is built for site owners who want to monetize traffic — whether you run a download portal, a blog, or a content site. The safelink page can show your own articles and your own ads, so 100% of the revenue goes to you.

How it works

  1. You enter a destination URL (e.g. a YouTube link).
  2. SafeLink generates a random 5–10 character ID, e.g. k9Xz2a, and stores the mapping in your browser localStorage.
  3. You receive a short URL like https://your-domain.com/s/?id=k9Xz2a.
  4. When someone visits that URL, SafeLink looks up the destination from localStorage, displays an article page with a countdown timer, then redirects them to the destination.
  5. Two modes: Shortlink (auto-redirects when timer ends) and Safelink (requires the visitor to click a button manually — better for monetization because it forces an ad impression).

Key principles

  • No database: All mappings live in browser localStorage. No backend to maintain or pay for.
  • No server: Pure static site (HTML, CSS, JS). Deploy to GitHub Pages, cPanel, Netlify, anywhere.
  • Self-hosted: You own the files. No third-party servers see your traffic.
  • Monetization ready: Supports Google AdSense, Adsterra, Monetag, MGid, PropellerAds, and any ad network.
  • Global: Works on any browser, any IP, any country. No geographic limits.

Limitations (be honest)

  • Links created in one browser cannot be opened in another browser (localStorage is per-browser).
  • Anyone with the URL can decode the destination (encoding is for shortening, not for secrecy).
  • Clearing your browser data will erase all generated links from that browser.

If you need cross-device links or secret URLs, you need a database-backed service — SafeLink static is not the right tool for those use cases.
